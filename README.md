# Shova Rani, academic website

Plain HTML, CSS and JS, hosted on GitHub Pages. No build step.

Live at https://shovarani-buet.github.io/shovarani-buet/

## Layout

- One HTML file per section: index, academics, research, publications, projects, experience, awards, skills, leadership, story, gallery, cv, contact, 404.
- `assets/css/site.css` holds all styling, `assets/js/site.js` all behavior.
- `assets/img/` has the processed photos (800 px and 1600 px versions, original proportions).
- `assets/docs/shova-rani-cv.pdf` is the downloadable CV.

Original photos and the source CV are kept locally in `assets_raw/` and are not part of the repository.

## Local preview

Run `python -m http.server` in this folder and open http://localhost:8000.
